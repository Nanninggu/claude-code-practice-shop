점검 대상: $ARGUMENTS
이 대상을 저장소에서 찾아 읽고, 아래 일곱 관점으로 점검해 줘.

1. 소스와 설정에 박힌 시크릿
2. 문자열을 이어 붙여 만드는 쿼리
3. 인증 없이 열려 있는 엔드포인트
4. 남의 데이터에 접근할 수 있는 엔드포인트
5. 로그와 저장소에 남는 카드번호 같은 민감정보
6. 입력값을 그대로 화면에 출력하는 곳
7. 엔티티를 그대로 내보내는 응답

지킬 것
- 관점마다 해당하는 곳을 파일과 줄로 적고, 없으면 없다고 적어.
- 코드를 읽어서 확인한 것과 추측을 나눠.
- 코드는 고치지 마.
- 답에는 절대 경로를 적지 마.
- 끝에 관점별 건수를 표로 정리해.
